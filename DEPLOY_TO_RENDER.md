# Инструкция по развертыванию Агента 1С на Render.com

Этот проект полностью подготовлен для развертывания в облаке **Render.com** и будет работать **1-в-1 как на локальном компьютере**, доступный по публичной ссылке (например, `https://psg-1c-agent.onrender.com`).

---

## 🚀 Пошаговый план запуска (за 3–5 минут):

### Шаг 1. Загрузить проект в свой GitHub (или GitLab)
1. Создайте новый репозиторий на [github.com](https://github.com/new) (например, `psg-1c-agent`), приватный или публичный.
2. Откройте терминал в папке проекта и отправьте код в GitHub:
   ```bash
   git init
   git add .
   git commit -m "Initial commit for Render deployment"
   git branch -M main
   git remote add origin https://github.com/<ВАШ_АККАУНТ>/psg-1c-agent.git
   git push -u origin main
   ```

---

### Шаг 2. Создать Web Service на Render.com
1. Перейдите в панель [dashboard.render.com](https://dashboard.render.com/).
2. Нажмите кнопку **«New +»** в верхнем правом углу и выберите **«Web Service»**.
3. Выберите **«Build and deploy from a Git repository»** и нажмите **Next**.
4. Подключите ваш GitHub-аккаунт и выберите репозиторий `psg-1c-agent`.

---

### Шаг 3. Настройки на Render:
Render автоматически обнаружит файл `Dockerfile` в корне проекта!

* **Name**: `psg-1c-agent` (или любое другое имя)
* **Region**: Frankfurt (Германия) или любой ближайший
* **Language**: `Docker` (выберется автоматически)
* **Instance Type**: `Free` (бесплатный тариф)

Нажмите **«Create Web Service»** внизу страницы.

---

### Шаг 4. Готово! 🎉
* Render запустит сборку Docker-образа, автоматически установит Python, Tesseract OCR с русским языковым пакетом и все библиотеки.
* Через 2–3 минуты статус изменится на **«Live»**, и вверху появится постоянная защищенная ссылка `https://psg-1c-agent.onrender.com`.
* Любой менеджер сможет заходить по этой ссылке с любого компьютера или телефона, загружать файлы заявок и мгновенно скачивать готовые `.xlsx` для 1С!

---

### 💡 Важные особенности бесплатного тарифа Render:
* **Спящий режим (Spin down)**: если сайтом не пользуются 15 минут, бесплатный инстанс засыпает. При первом обращении менеджера он просыпается за 30–50 секунд, после чего работает быстро.
* **HTTPS**: бесплатный SSL-сертификат подключается автоматически.
* **Авто-деплой**: при любых изменениях в GitHub Render автоматически пересоберет и обновит приложение.

# Интеллектуальный Агент обработки заявок на обучение для 1С
### ЧОУ ДПО ЦЕНТР "ПСГ" (Версия 2.0 с Веб-Интерфейсом и Аудитом Регламентов)

Агент предназначен для автоматической обработки входящих заявок от заказчиков в поддерживаемых форматах, проверки регламентов видов обучения, комплектности документов, исправления ошибок и генерации файла Excel (`.xlsx`), готового для бесшовной загрузки в 1С.

---

## 🎨 Веб-интерфейс в корпоративных цветах ПСГ

Система оснащена современным веб-интерфейсом в фирменной палитре компании (Белый, Черный, Серый, Красный) с официальным 3D-логотипом центра.

### Быстрый запуск веб-интерфейса:
```bash
./start_web.sh
# или
python3 web_app.py
```
После запуска откройте в браузере: **`http://localhost:8000`**

## 🚀 Возможности системы

### 1. Поддерживаемые форматы входящих заявок:
- **Файлы заявок**: Word (`.docx`, `.doc`), Excel (`.xlsx`, `.xls`), `PDF`, фото/сканы (`JPEG`, `PNG`, iPhone `HEIC`).
- **Сырой текст сообщения**: вставка скопированного текста из WhatsApp, Telegram, Email.
- **Пакеты документов (сканы СНИЛС, паспорта, дипломы)**: с возможностью ручного указания программы, сроков, должности и отметок о наличии документов менеджером.

### 2. Программы и сроки (обновление 23.09.2026)

Актуальное описание реализации и ограничений: [docs/RECOGNITION_RELEASE.md](docs/RECOGNITION_RELEASE.md).

- Программы сверяются с прайсом и списком ДПП; профессии приказа №534 не считаются автоматически курсами центра.
- Часы берутся из конкретного варианта программы. Для ОТ В/СИЗ/ПП доступны 16 часов по умолчанию и явный выбор 8. Для высоты и ОЗП требуется группа, длительность 24 часа. Две экологические программы — 72 часа по прайсу.
- Учебные дни: округление часов / 8 вверх; календарь РФ 2025–2027 с рабочими субботами по переносам. Программы распределяются последовательно. Недостаточный интервал не сокращает курс.
- Дата приёма/трудоустройства означает начало. Значение одиночной даты без подписи нужно уточнить. Дата документа не используется как конец обучения.
- Нет программы, часов или календаря — предупреждение и черновик, без выдуманных сроков.
- Последовательность является правилом центра; приложение не подтверждает юридическую допустимость учебного плана. Существующие предупреждения о давности окончания 3/30 дней сохранены как старые внутренние проверки, не как вывод из законодательства.

### 3. Проверка обязательного пакета документов:
- **ПК, ДПП**: ФИО, дата рождения, номер СНИЛС, скан диплома об образовании.
- **Рабочие профессии**: ФИО, дата рождения, номер СНИЛС, фото 3х4.
- **ОТ (А, Б, В, СИЗ, ПП)**: ФИО, дата рождения, номер СНИЛС, должность.
- **Допуски, высота, ОЗП**: ФИО, дата рождения, должность, фото 3х4.
- **Ежегодная проверка знаний**: ФИО, дата рождения, номер или скан удостоверения.

### 4. Автоматическое исправление ошибок:
- **Должности**: автокапитализация с заглавной буквы, раскрытие сокращений (`м/к` $\rightarrow$ `металлоконструкций`, `пом.` $\rightarrow$ `Помощник`, `э/г` $\rightarrow$ `Электрогазосварщик`, `ж/б` $\rightarrow$ `железобетонных конструкций` и др.).
- **Программы**: распознавание сокращений (например, `Пожарка`, `ПТМ` $\rightarrow$ официальные программы пожарной безопасности МЧС).
- **Склонение ФИО**: автоматический перевод в Дательный падеж (Именительный ➔ Дательный).
- **СНИЛС**: валидация длины (11 цифр) и официальной контрольной суммы ПФР/СФР.
- **Омоглифы**: автоматическая замена скрытых латинских букв в русских словах.

### 5. Подсветка спорных данных и генерация Excel для 1С:
- **В самом Excel-файле**: текстовые комментарии убраны по требованию менеджера, спорные ячейки подсвечиваются **чистым желтым цветом (`#FFFF00`)**.
- **В веб-интерфейсе**: выводится **отдельное окно аудита и комментариев** с подробным описанием каждой ошибки и подсказками.
- 100% эталонное форматирование 1С: Arial 8/9pt, точные высоты строк, ширины столбцов, объединенные строки программ `#9999FF`.

## 🛠 Запуск через командную строку (CLI)

Обработка файла:
```bash
python3 psg_agent.py --input "Исходники/Пример заявки от заказчика 2.docx"
```

Обработка текста сообщения:
```bash
python3 psg_agent.py --text "Иванов Иван Иванович, 12.05.1985, 189-878-867 92, монтажник м/к, Пожарка, 01.09.2026 - 15.09.2026"
```

Запуск тестов:
```bash
python3 test_web_app.py
python3 test_agent_edge_cases.py
```

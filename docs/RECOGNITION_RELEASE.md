# Распознавание и расчёт сроков: реализация от 23.09.2026

Изменения подготовлены в отдельной копии `implementation`, ветка `recognition-quality`, на основе `b6f6253`. Исходная папка на рабочем столе и production не обновлялись. Это результат реализации согласованных правил, а не подтверждение безошибочного распознавания любых документов.

## Что изменилось

- Программы из обращения над таблицей сохраняются, включая текст на той же строке после «просим обучить». Явная программа в строке имеет приоритет над общей программой. Должность без программы не превращается в направление обучения.
- Колонки приёма, трудоустройства, выхода на работу и начала обучения обозначают начало. Колонки окончания обозначают конец. В тексте сохраняется смысл подписанной даты. Дата выдачи заявки не служит сроком обучения. Неподписанная одиночная дата требует выбора её смысла.
- Справочник построен из прайса, списка ДПП и актуальнейшего предоставленного текста приказа №534. Названия, разряды, группы, источники и доступные часы сохраняются отдельно. Приказ №534 используется как справочник профессий, а не подтверждение наличия курса у центра.
- Точное совпадение, известные однозначные сокращения ОТ и группы высоты/ОЗП допускают автоматический выбор. При похожих или неоднозначных названиях возвращаются кандидаты, но назначение не происходит. В интерфейсе оператор выбирает программу из поиска.
- Все учебные дни считаются по федеральному производственному календарю РФ, включая перенесённые рабочие субботы. Поддержаны 2025–2027 годы. За пределами этих лет расчёт останавливается с предупреждением.
- Длительность = округление вверх `часы / 8`; начальный и конечный учебный дни включаются в срок. Все курсы одного слушателя планируются последовательно в порядке заявки/выбора оператора. Недостаточный интервал не приводит к сокращению курса.
- ОТ В, СИЗ и ПП: по умолчанию 16 часов, выбор 8 часов. Высота/ОЗП с группой: 24 часа. Специальные 8-часовые работы из раздела ОТ В остаются отдельными программами. Экология B5:C6: 72 часа по прайсу. ДПП по охране труда: 256 часов, не общие 250. Рабочие программы учитывают разряд и часы конкретной строки прайса.
- У явно выбранной программы без часов оператор может указать подтверждённую длительность. У программы с известными вариантами допускаются только эти варианты. 178 часов не назначаются всем пожарным программам. 144 часа не подставляются автоматически вместо 72 часов закупочного курса из прайса.
- При отсутствии слушателей возвращается ошибка, без выдуманного слушателя. При неподтверждённых программе/сроках результат обозначается как черновик. СНИЛС проверяется без подбора замены цифры ради контрольной суммы.
- Для структурированного PDF/DOCX с найденными слушателями и программами используется локальная таблица; запрос к ИИ не требуется. Для остальных случаев сохранён существующий OCR/ИИ. Исправлена неопределённая переменная каталога временных страниц PDF; уточнены инструкции извлечения ИИ.

## Справочники

`data/training_catalog.json`: 723 записи программ и вариантов: 649 доступны по предоставленным спискам, 47 демонстрационных, 27 исключённых. Это количество записей/вариантов, а не уникальных образовательных лицензий или юридически утверждённых учебных планов. Включены все 115 позиций списка ДПП: совпадающие названия объединены с прайсом, остальные сохранены без выдуманных часов.

106 доступных записей не содержат часов в источнике. Список для заполнения: [catalog-hours-to-confirm.csv](catalog-hours-to-confirm.csv). Это не ошибка импорта: в PDF ДПП часы не приведены, а в некоторых строках прайса их также нет. Справочник профессий содержит 5168 нумерованных записей предоставленной редакции приказа, включая добавленные номера в скобках. Неуказанные/объединённые в исходнике коды не восстанавливаются догадками.

Импорт: `python3 tools/import_training_catalog.py PRICE.xlsx DPP_EXTRACTED.txt ORDER_EXTRACTED.txt data/training_catalog.json`. Нужен установленный openpyxl, уже используемый проектом. Извлечённые тексты должны соответствовать структуре предоставленных PDF/RTF; импорт других шаблонов требует проверки. SHA-256 входов сохраняются. Секреты, цены и данные слушателей в справочник не включены. Обновление JSON требует перезапуска сервера (кэш справочника).

## Юридическое основание и границы

Проверены разделы II правил [№782н](https://www.consultant.ru/document/cons_doc_LAW_371453/e2b2e6742278cd3c52fd6b13a9d4ec9779e0af33/) и [№902н](https://www.consultant.ru/document/cons_doc_LAW_373156/a805618beadbbed7f39fdd6b4e84463ad4aa2a87/). Пункт 28 №902н предусматривает программу ОЗП с изучением работ на высоте и допускает единые либо отдельные документы по оценке навыков. Основания объявлять любую комбинацию высоты и ОЗП запрещённой не установлено. Последовательное расписание реализовано как согласованная политика центра. Оно не заменяет проверку учебных планов, практических занятий, экзаменов и стажировки. Стажировка работодателя не добавляется автоматически к часам курса. В правилах высоты она регулируется отдельно (пункты 28–30).

24 часа из прайса и расчёт 8 часов в день являются входными правилами центра, а не утверждением о единой обязательной длительности по закону. Сокращённые предпраздничные рабочие дни считаются учебными днями по согласованной формуле; календарь не рассчитывает норму рабочего времени преподавателя. Региональные праздники не включены.

Календарь основан на постановлениях о переносах: [2025 — №1335](https://storage.consultant.ru/ondb/attachments/202410/04/iddoc_286124_idnews_56549_Vyhodnye_2025_sVh.pdf), [2026 — №1466](https://publication.pravo.gov.ru/document/0001202509240023), [2027 — №1187](https://www.consultant.ru/document/cons_doc_LAW_544706/). Для 2027 используется опубликованное постановление от 17.09.2026, не ранний проект. Рабочая суббота 20.02.2027 учтена.

Новый GET `/api/programs?q=...`: версия, total, первые 100 доступных записей; поиск по названию. POST `/api/process` дополнен `date_role=auto|start|end`, `hours_overrides` — JSON-объект `{id_программы: целые_часы}`. Неправильный формат даёт 422. Существующие поля и выгрузки DOCX/XLSX сохранены.

В ответе добавлены `requires_review`, `catalog_version`; у групп — hours, days, source, candidates, schedule_warning; у слушателей — recognition с исходными программой/датой и признаком ручного выбора. При нескольких слушателях ориентируйтесь на метаданные строки: сводка группы показывает параметры первого слушателя.

## Проверки

`python3 tools/run_quality_tests.py` запускает старые и новые тесты в временной копии, без сети и загрузки .env. Логи с содержимым заявок подавляются. Результат: 62 проверки, 60 успешных, 2 пропущены, 0 ошибок; [validation.json](validation.json). В старых тестах изменены ожидания, непосредственно заменённые согласованными правилами: запрет угадывания профессии/разряда, сохранение сомнительного СНИЛС, названия по прайсу, явный смысл одиночной даты, локальное извлечение структурированных таблиц.

Через браузер проверены поиск ОЗП (отдельно 24-часовые группы и 8-часовые работы), выбор программы, явное начало обучения, обработка синтетической заявки, отображение двух последовательных интервалов, скачивание Word/Excel и проверка дат внутри скачанных документов. Отчёт: [browser-validation.json](browser-validation.json).

Отдельно локально проверена заявка №68. Это один из случаев, не универсальный шаблон: два человека, четыре записи; высота 2 — 24–26.08.2026, ОЗП 2 — 27–31.08.2026. Оригинал не включён в новые публичные тестовые данные. Тесты используют синтетические ФИО. Реальные запросы к платному ИИ не выполнялись.

## Что ещё требуется для полной приёмки

1. Заполнить часы для 106 записей и разрешить расхождения похожих названий между прайсом и PDF. Для ПК пожарной безопасности 178 часов требуется точное наименование утверждённого курса. Неуказанные варианты ПК/ДПП/допусков нельзя назначить только по общему типу.
2. Предоставить обезличенную контрольную выборку разных заявок с подтверждёнными ответами: сканы, фотографии, рукопись, многостраничные документы, неоднозначные строки и разные организации. Без неё процент точности распознавания НЕ ОПРЕДЕЛЁН — требуется измерение, а не обещание «любого вида».
3. Приёмка реального ИИ на согласованной выборке с доступом к API и условиями передачи персональных данных. Сейчас проверены локальные маршруты и имитация ответа ИИ.
4. Перед публикацией закрыть замечания предыдущего security-аудита (авторизация, доступ к выгрузкам, имена загрузок, XSS и Excel-формулы). Эта ветка не заявляется полной реализацией security-аудита.
5. Проверить реальные названия/идентификаторы номенклатуры в 1С. Предоставленные файлы не содержат полного справочника идентификаторов 1С.

Не реализованы: обучение собственной OCR-модели, база подтверждений операторов, семантический поиск с эмбеддингами, автоматическое обновление календарей из сети, интерактивное исправление каждой ячейки результата. Предложения похожих программ доступны в API; для подтверждения используется поиск и повторная обработка заявки. Текущий механизм OCR сохраняет ограничения на сложные документы. Общий процент документированности/точности по одному примеру не вычисляется.

## Запуск и передача

Из этой копии: `python3 -m uvicorn web_app:app --host 127.0.0.1 --port 8768`. Папка `data` должна быть включена при переносе. Новые сторонние зависимости приложения не добавлены. Для проверки интерфейса установлен навык Playwright; дополнительно установлен security-best-practices. Установка навыков не изменяет приложение и не публикует сайт.

Не переносите изменения в production простым копированием поверх работающего сервиса. Сначала приёмка этой ветки и закрытие необходимых замечаний аудита, затем отдельное согласование публикации. Откат испытательной копии — запуск исходной папки, которая не менялась.
